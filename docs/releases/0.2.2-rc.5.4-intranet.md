# Win7 内网适配预览版 0.2.2-rc.5.4

根据 2026-11-26 的 Win7 SP1 x64 真机报告修改。

- PowerShell 长输出超过进程捕获和消息预算两层限制时，工具结果把二次存储的文件标为格式化预览，并在提示末尾保留完整原始 stdout 或 stderr 的路径。若完整原始文件无法保存，提示会明确标为不可用。
- Windows 桌面为子进程默认设置 UTF-8 Python 标准流，保留用户显式设置。仍使用其他编码的原生命令应按该命令的文档设置输出编码。
- 工具 PATH 可直接调用包内的 `python`、`node` 和离线 `pnpm`。系统 PATH、现有沙箱权限不受影响。安装包未包含 npm 和 Git。

用户已在上一版验证 PowerShell、文件编辑、沙箱、后台任务、子代理、Python/Node 与中文 DOCX。此版保留相同的社区兼容二进制，仍为未签名预览版。此版的 Win7 真机复测、CIM/WMI 与 PowerShell 回环 HTTP 的现场诊断尚待进行。[验证记录](https://github.com/Sebastian6848/DeepSeek-Harness-in-Win7/blob/main/docs/validation.md)
