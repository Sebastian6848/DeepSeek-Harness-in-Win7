# Win7 内网适配预览版 0.2.2-rc.5.3

适用目标：Windows 7 SP1 x64，连接单位内网的 OpenAI 兼容模型服务。基于 factfinding 的 Win7 运行时和官方 0.2.2-rc.5 主体；官方目前没有非预发布稳定版。

安装包包含本项目编译的改动：

- 模型设置默认打开自定义 API，协议为 OpenAI Chat Completions，模型名 `ds`；网址、模型和可选密钥均可编辑。
- 默认停用外部搜索/抓取、公网 DeepSeek 账号与模型路由、账号刷新、遥测、插件市场/MCP 自动启动；不启动自动更新，不携带更新源。
- 保留原有文件编辑、受权限控制的终端和会话机制。内网模型服务须支持工具调用。
- 复用已固定 SHA256 的社区兼容二进制，保留许可与来源；重建本项目的应用代码及运行时完整性清单。

下载 `deepseek-harness-0.2.2-rc.5.3-win7-x64-intranet-unsigned.exe` 和 `SHA256SUMS.txt`。校验后搬运到办公电脑离线安装。系统补丁、VC++/UCRT 等前置要求见仓库 README，模型服务地址需要使用单位提供的真实地址。

验证证据：12 项根目录测试、366 项相关源码回归、完整构建 10 个阶段及后续 Host/Client 类型检查通过；真实 ASAR 的 Linux/Windows 路径及 unpack 集成测试通过。Windows 11 x64 开发机已启动实际打包 Host 与 Electron 模型设置界面；冷启动、前端访问、默认表单和 Host 正常退出通过；缺省环境复测也通过。20,619 个最终运行时文件通过哈希核对，NSIS 解包后全部 8,895 个物理文件与准备目录一致。Node socket 和页面请求的测试观察窗口内未见外网目标。
